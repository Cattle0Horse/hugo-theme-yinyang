本篇文章演示主题的 markdown 表格样式。样式特征：水平线制（无垂直边框）、表格居中、表头与偶数行灰底斑马纹、灰底行内的行内代码使用次级底色。

## 基础表格

最简单的表格，不写任何对齐标记，表头默认样式：

| 名称 | 版本 | 说明 |
| --- | --- | --- |
| Go | 1.22 | 静态编译、并发原语 |
| Hugo | 0.125 | 静态站点生成器 |
| Nix | 2.24 | 可复现的包管理 |

## 对齐语法

通过 `:---`（左）、`:---:`（居中）、`---:`（右）控制单元格对齐，主题尊重 markdown 规范，不做额外覆盖：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 默认居左 | 居中显示 | 数字右对齐 |
| 第二行 | 12345 | 6.28 |

## 含行内代码的表格

斑马纹灰底行内的行内代码会使用次级底色（`--color-table-code-bg`），避免与斑马纹撞色：

| 类型 | 表达式 | 结果 |
| --- | --- | --- |
| 整数 | `2 + 3` | `5` |
| 浮点 | `1.5 * 2` | `3.0` |
| 字符串 | `"a" + "b"` | `ab` |
| 布尔 | `1 < 2` | `true` |

## 多行表格

行数较多时，偶数行（第 2、4、6 行）为灰底斑马纹，奇数行透明：

| 排序 | 算法 | 平均时间复杂度 | 额外空间 |
| --- | --- | --- | --- |
| 1 | 插入排序 | O(n²) | O(1) |
| 2 | 归并排序 | O(n log n) | O(n) |
| 3 | 堆排序 | O(n log n) | O(1) |
| 4 | 快速排序 | O(n log n) | O(log n) |
| 5 | 计数排序 | O(n + k) | O(k) |
